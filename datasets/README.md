# Dataset metadata notice

The initial metadata files in this directory were substantially generated with language model
assistance. They may contain transcription errors, outdated details, incomplete source coverage, or
incorrect interpretations. Treat them as an editable catalog, not as authoritative provider
documentation.

Check important facts against the cited provider pages, data files, and publications before relying
on them. A `verified_on` date records when listed sources were checked; it does not mean the dataset
was downloaded, benchmarked, or independently validated.

Human corrections and additions are welcome. Use [the index](../INDEX.md) to find the paired
guidance and metadata files, then open a pull request with the supporting source and its scope.
